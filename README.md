# Vanguard

**Vanguard** is a decentralized, offline disaster management system built with Flutter and ESP32 Mesh networking.

## Key Features
- **Offline Mesh Chat:** Communicate without internet or cellular network.
- **Rescue Dashboard:** Real-time monitoring of victims and sensor data.
- **Sensor Monitoring:** Integrated temperature, fire, and seismic activity detection.
- **Capative Portal:** Easy access for disaster victims via local Wi-Fi.

## Tech Stack
- **Flutter:** Mobile application.
- **ESP32:** Mesh network nodes.
- **painlessMesh:** Decentralized communication protocol.
- **ArduinoJson:** Data serialization.
